# EPL v2.0.0 Release Notes — Signature Design Experience

**Release Version:** `2.0.0`  
**Release Date:** November 19, 2026  
**Status:** Formally Verified Release  
**Codename:** Signature Design Experience  
**Git Commit Reference:** `ab69371`  

---

## 1. Executive Summary

EPL v2.0.0 represents a major milestone in visual identity and motion design. It replaces conventional dashboard layouts with an original bespoke geometric vector brand identity, a tactile 3D Page-Curl theme transition, an interactive desktop magnetic cursor, a cinematic landing page at `/` (preserving `/dashboard`), and transformed Athlete Performance Dossiers.

---

## 2. Detailed Deliverables

### 1. Original Brand Identity System (`EplBrandLogo.tsx`)
* Custom geometric vector crest integrating three kinetic stump pillars, aerodynamic ribbons forming 'EPL', a cricket ball seam orbit, and an apex telemetry sensor.
* Scalable across `full`, `monogram`, `hero`, `icon`, and `horizontal` variants.
* Custom favicon installed at `frontend/public/favicon.svg`.

### 2. Signature 3D Page-Curl Theme Transition (`PageCurlTransition.tsx`)
* Physics-driven corner-fold animation triggered by the Sun/Moon theme toggle.
* Simulates peeling a physical high-gloss page with perspective folding, crease shadowing, and zero FOUC.
* Automatically disabled when `prefers-reduced-motion` is active.

### 3. Custom Desktop Interactive Cursor (`CustomCursor.tsx`)
* Spring-lagged magnetic follower (`damping: 28, stiffness: 320`) with precision central target.
* Contextual expansion to 64px with a `"VIEW"` micro-badge on interactive elements.
* Dormant on touch and mobile devices.

### 4. Athlete Performance Dossier (`/players/[id]`)
* Oversized Space Grotesk headline styling with initials monogram crest.
* Gold/blue halo ring for marquee tier players ($\text{PIS} \ge 75$).
* 6-over cricket milestone rack (10+, 15+, 20+ runs; 2+ wickets).
* 100-Point PIS interactive card with micro-progress meters.
