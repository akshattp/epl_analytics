# EPL v2.0.1-dev Release Notes — Creative Overhaul, Landing Page Reconstruction & Documentation Governance

**Development Tag:** `2.0.1-dev`

**Status:** In Progress / Active Sprint  
**Codename:** Creative Overhaul, Landing Page Reconstruction & Documentation Governance  

---

## 1. Problem Statement & Motivation

Following version 2.0.0, user audits identified two key issues:
1. **Critical Data Binding Bug**: Featured athlete cards in the landing page displayed `0` for Career Runs and `0` for Career Wickets because the frontend attempted to access non-existent nested properties (`p.career_batting?.total_runs`).
2. **Generic AI-Generated Layouts**: Sections 01 and 03 consisted of identical repetitive 3-box cards that felt generic and automated rather than professionally art-directed.
3. **Documentation Decay**: Release history between v1.3.0 and v2.0.0 had not been rigorously documented in `CHANGELOG.md` or centralized registers.

---

## 2. Scope of Changes in 2.0.1-dev

### 1. Functional Bug Fix: Player Runs & Wickets
* **Backend (`backend/services/player_service.py`)**: Enriched `get_all_players_summary` so that every player dictionary contains flat metrics (`total_runs`, `wickets`, `strike_rate`, `economy`) AND nested dictionaries (`career_batting`, `career_bowling`).
* **Frontend (`frontend/src/app/page.tsx`)**: Rebound athlete cards using defensive coalition (`p.total_runs ?? p.career_batting?.total_runs ?? 0`).
* **Test Verification**: Added `tests/test_v2_0_1_governance_and_fixes.py` verifying that all active players render accurate non-zero numbers.

### 2. Complete Creative Reconstruction of Landing Page
* **Multi-Layer Parallel Scrolling Experience**: Integrated `framer-motion` scroll tracking (`useScroll`, `useTransform`) to coordinate movement between oversized typography, floating telemetry chips, and kinetic trajectory vectors.
* **Redesigned Section 01: The Competitive Architecture**: Completely replaced the generic 3-box cards with an **Asymmetric Competition Architecture Showcase**:
  * Left: High-impact editorial panel explaining 6-over underarm mechanics (36 balls, high leverage, ₹100L purse cap).
  * Right: Interactive 6-Franchise Competition Grid displaying team colors, Captains, Squad counts, and Net Run Rates.
  * Bottom: 100-Point PIS mathematical pillar strip.
* **Redesigned Section 02: Marquee Athlete Dossiers**: Horizontal parallax scrolling sequence of verified players with live database runs and wickets.
* **Redesigned Section 03: Data Intelligence Cockpit**: Replaced 3 generic cards with an asymmetric analytics command center.

### 3. Permanent Documentation Governance
* Created master tracking files: `CHANGELOG.md`, `VERSION_HISTORY.md`, `RELEASE_REGISTER.md`, `CURRENT_SYSTEM_INVENTORY.md`, `UI_UX_CHANGELOG.md`, `DESIGN_SYSTEM.md`.
* Created automated verification script `scripts/verify_documentation_governance.py`.
